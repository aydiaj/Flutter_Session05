# Session 05 · Public DartPad examples

18 complete, runnable and intentionally editable Dart programs. Each exercise has one independent `main.dart` and a unique key in `examples/manifest.json`.

Publish these **teaching examples only** using `python tools/publish_gists.py --publish` after setting `GITHUB_TOKEN`. The script updates `js/gists.js` for the website. It never reads or publishes the instructor answer keys.

The website code samples are generated from the same `main.dart` sources and match them byte-for-byte apart from HTML escaping. Multi-file library privacy is shown separately in `reference/privacy-across-files/`.
